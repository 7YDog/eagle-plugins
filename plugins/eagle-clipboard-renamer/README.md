# 剪贴板一键重命名 (eagle-clipboard-renamer)

> Eagle 轻量后台服务型插件（`serviceMode: true`）。  
> 专为 **OCR 提取视频标题后快速贴名** 场景设计：无界面弹窗打扰，一键读取最新剪贴板文字，直接重命名选中的素材。

---

## 🌟 核心特性

- **极致轻量无感**：采用 Eagle `serviceMode`，插件启动时不产生多余空白窗口，不占屏幕空间。
- **纯净贴名**：忠实使用剪贴板提取出的标题文字，不强制附加日期、前后缀或任何特殊格式。
- **智能字符清洗**：自动剔除操作系统非法文件名符号（`\ / : * ? " < > |`），自动合并多余换行与空格，保障 Eagle 库数据安全。
- **多选智能适配**：
  - 单个素材：直接重命名为提取的标题；
  - 多个素材：若剪贴板含多行标题且行数匹配，按行一一对应重命名；否则自动附加递增序号（如 `标题 (2)`、`标题 (3)`）防止重名冲突。
- **即时通知**：重命名完成或异常时，通过 Eagle 原生气泡（Toast）实时提示结果。

---

## 🚀 使用工作流（推荐联动 OCR）

1. **提取标题**：使用系统自带截图 OCR（如 macOS 访达/微信/PixPin 等 OCR 工具）框选视频第一帧或封面上的大标题，识别并自动复制到剪贴板；
2. **选中素材**：在 Eagle 列表或网格中点击选中对应的视频或素材；
3. **一键贴名**：点击 Eagle 右上角或插件栏的「剪贴板一键重命名」图标，或者按下你配置的快捷键（推荐 `Cmd+Shift+R`）；
4. **完成**：素材名称瞬间更新为识别出的标题文字！

---

## ⌨️ 快捷键设置建议

在 Eagle 偏好设置中：
1. 打开 **Eagle 首选项 -> 快捷键 -> 插件**；
2. 找到 **剪贴板一键重命名**；
3. 设置为你顺手的快捷键（如 `Cmd + Shift + R` 或 `Ctrl + Shift + R`）。

设置完成后，工作流将提升为：「**OCR 复制 -> 选视频 -> 按快捷键**」，3 秒完成素材重命名。

---

## 🛠️ 安装说明

将本目录直接复制或软链接至 Eagle 的 Plugins 目录：

**macOS 路径**：
```bash
~/Library/Application Support/Eagle/Plugins/eagle-clipboard-renamer
```

**Windows 路径**：
```text
%APPDATA%\Eagle\Plugins\eagle-clipboard-renamer
```

复制后重启 Eagle 或通过开发者菜单重载插件即可生效。
