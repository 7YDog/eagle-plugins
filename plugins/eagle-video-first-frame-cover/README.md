# 切换视频首帧封面

从 Eagle 中选择一个或多个视频，提取第 0 秒的首帧画面，并将其设置为视频的自定义缩略图。

## 功能

- 点击插件 / 快捷键后**无弹窗**直接执行，右上角 notification 提示结果。
- 支持同时处理多个视频。
- 支持 MP4、WebM、AVI、MOV、MKV、FLV、WMV 和 M4V。
- 通过 Eagle 的 FFmpeg 扩展提取画面（`eagle.extraModule.ffmpeg`），无需内置 FFmpeg / Homebrew 硬路径。
- `serviceMode` + 透明 1×1 窗口，体验对齐「获取封面路径」。

## 使用方法

1. 在 Eagle 中选中需要处理的视频。
2. 打开「切换视频首帧封面」插件，或使用为其绑定的快捷键。
3. 看右上角通知即可；无进度小窗。

## 版本

当前版本：1.0.5

依赖：Eagle FFmpeg 扩展。

兼容性：在 macOS Eagle 4.0 中，即使封面文件已经写入，插件有时收不到完成事件；插件会验证资源库中的缩略图文件并在超时后继续或报错，不会无限卡住。
